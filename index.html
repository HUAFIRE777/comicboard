漫画分镜与出版级原稿创作实战指南

如何利用经典四格网格、起承转合分镜节奏与酒精马克笔完成专业漫画创作与印刷排版

1. 经典四格与起承转合分镜节奏

顶部模版一键切换四格漫画或日漫 B5 原稿纸，在每格中合理分配景别（特写、中景、全景），用对白气泡框规划读者的视觉动线（从右上至左下）。

2. G 笔勾线与斜头酒精马克笔上色

使用 G 笔绘制富于弹性压感的人物体态主线，切换斜头酒精马克笔通过半透明正片叠底层层罩染阴影调子，搭配纯白高光笔点缀瞳孔与发丝光芒。

3. 双页并排对照与 300 DPI 打印 PDF

开启「双板并排」对照前后两页分镜的连贯性；完成后导出 300 DPI 高清打印 PDF（Pro 还可按 B5 投稿原稿、条漫长图或带页码的书籍 PDF 导出），或导出 SVG 在 Figma / Illustrator 中继续编辑。

AI Agent 浏览器自动化与协同绘图实战指南

支持 Claude / Codex / Antigravity / Playwright 等智能体通过浏览器自动化与标准 API 操作画板

1 控制台与自动化 API (window.EazyBoard)

智能体与无头自动化测试（Playwright / Puppeteer / Browser-Use）可调用全局 window.EazyBoard 接口：切换工具与颜色、添加笔画与文字、绘制矩形与直线、打开导出面板。

2 Computer Use 视觉光标与快捷键驱动

画板配备标准键盘快捷键（V 选择、P 画笔、E 橡皮、G 油漆桶、T 文字、H 抓手平移、? 快捷键一览），视觉智能体可以像创作者一样操作画布。

3 让模型生成笔画，人工精修后导出

让大模型依据分镜脚本输出笔画坐标或分格矩形，通过 EazyBoard.addStroke / drawRect 画到画布上，再手绘精修，最后导出 PNG / PDF / SVG。
